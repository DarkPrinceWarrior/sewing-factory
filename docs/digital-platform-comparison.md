# Сравнение швейной фабрики с Digital Platform и мобильным эталоном Marina Tracker

Сравнили десктопные страницы и общие компоненты фабрики с эталоном `digital_platform/frontend/src/`, а мобильный PWA-адаптив построили по архитектурной модели `marina_tracker`. Светлая тема (`#f7f7f7` фон, `#fff` карточки, `--primary: #723ceb`, `--link: #157b9c`, шрифт Inter с `tabular-nums`) и базовые пропорции макетов Figma (`226px` сайдбар, `64px` топбар, `44px` заголовок таблицы, минимальный шаг строки `56px`) на десктопе `>= 860px` сохранены без регрессий.

## Что перенесено по экранам и компонентам

| Область / страница | Что перенесено и доработано |
| --- | --- |
| Токены, PWA и стили (`web/style.css`, `web/index.html`, `web/public/*`) | Удалены дублирующие правила в `style.css`; добавлены токены состояний кнопок (`hover` изолирован в `@media (hover: hover)`, `:active` микро-отклик `scale(0.97)`, `focus-visible`, `disabled`, `.small`, `.danger`, `.text-button`), семантические цвета статусов (включая `.status.inactive`), тени, `prefers-reduced-motion`, адаптация для split-pane (`860px–1080px`) и аккуратный `@media print`. Выровнена `month.svg` (`18×18`, `stroke-width="1.26667"`), добавлены `receiving.svg`, `sales.svg`, `more.svg`, фирменная `icon.svg`, 4 PNG-иконки (`apple-touch-icon.png` 180×180, `icon-192.png`, `icon-512.png`, `icon-512-maskable.png`), `manifest.webmanifest` и `sw.js` (`factory-pwa-v1`, precache shell, network-first `/api/` с JSON 503 offline fallback, SWR для статики). |
| Мобильный PWA-адаптив и сервер (`< 860px`, модель `marina_tracker`, `app/main.py`) | На сервере подключены `GZipMiddleware(minimum_size=500)`, `PWAHeadersMiddleware` (`/sw.js` `no-cache` + `Service-Worker-Allowed: /`, `/manifest.webmanifest` `application/manifest+json`, `/assets/*` `immutable`, `/icons/*` `max-age=86400`, `/api/*` `no-store`) и ускорены `overview()`/`detail()` в `app/read_model.py`. ## Выверенные ролевые границы (сервер ↔ UI)

| Роль | Серверные и интерфейсные ограничения |
| --- | --- |
| `admin` | Полный доступ к центральным и региональным реестрам, созданию материалов (`POST /api/materials`), продажам со склада Иваново ID=5 и региональных складов (`POST /api/sales`), созданию региональных складов (`POST /api/warehouses`) и управлению доступом кладовщиков (`/api/access`). На мобилке `BottomNav` (5 вкладок) + `MoreSheet`. |
| `accountant` | Весь учёт производства, сырья (включая `POST /api/materials` и `target_id`), перемещений, продаж (включая Иваново ID=5 через `#/sales/new`), каталога, сотрудников, зарплаты и итогов месяца; запрещены создание складов и управление доступом (`/api/access` → 403; в UI скрыты кнопки, прямой переход показывает `AccessDenied`). |
| `master` | Обзор, отчёты за смену (создание и проведение; выбор `source_id` ограничен складами Иваново `kind != 'regional'`, чужой склад → 403; исправление скрыто в UI и запрещено на сервере — 403), 5 складов Иваново (включая движения `opening` только по центральным складам), просмотр каталога и личных данных сотрудников без начислений и Excel (`rows: []`, `?xlsx=true` → 403). Недоступны `POST /api/materials`, `POST /api/sales`, `/payroll`, `/month`, `/stock/receipts*`, `/stock/transfers*`, `/stock/sales*`, `/stock/access` (в мобильной шторке `MoreSheet` только Сотрудники, Настройки и Выход). |
| `regional` | Только свой привязанный склад, его приёмки, продажи (`POST /api/sales` жёстко фиксирован на `user.warehouse_id`, сводка `payments` по своему складу) и `#/settings`. Из всех JSON и Excel ответов (`stocks`, `warehouse_history`, `list_documents`, `detail`, `sales_summary`, `movements?xlsx=true`) и UI (`StockHistory`, `DocumentHistory`) полностью исключена внутренняя учётная себестоимость (`value`, `book_value`, `cost`) — показываются только розничные цены. Отзыв доступа, деактивация сотрудника или смена `staff.stage` с `'warehouse'` аннулируют активные сессии; смена пароля завершает прежние сессии кроме текущей. На мобилке `BottomNav` из 4 вкладок (Остатки, Приёмка, Продажи, Настройки). |
