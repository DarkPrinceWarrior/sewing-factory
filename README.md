# Швейная фабрика

Локальное десктопное веб-приложение. Интерфейс на React, сервер на FastAPI, данные хранятся в SQLite. Макеты находятся на странице швейной фабрики в Figma.

## Запуск в WSL

```bash
cd ~/sewing_factory
./run.sh
```

Откройте [локальное приложение](http://localhost:8096/). Чтобы выбрать другой порт, запустите `FACTORY_PORT=8098 ./run.sh`.

Первый запуск создаёт `data/factory.sqlite3` и заполняет её производственной историей с января 2025 года по день запуска. Данные вымышленные. Повторный запуск сохраняет созданные пользователями документы. Скрипт `uv run pytest -q` работает с отдельной временной базой.

## Вход

Все начальные локальные учётные записи используют пароль `Ivanovo!2026`.

| Учётная запись | Роль |
| --- | --- |
| `admin@factory.local` | Администратор фабрики |
| `oksana@factory.local` | Бухгалтер |
| `master@factory.local` | Мастер смены |
| `moscow@factory.local` | Кладовщик, Москва |
| `petersburg@factory.local` | Кладовщик, Санкт-Петербург |
| `yaroslavl@factory.local` | Кладовщик, Ярославль |
| `nizhny@factory.local` | Кладовщик, Нижний Новгород |

Кладовщик видит остатки своего склада, входящие отправки и местные продажи. Приёмка зачисляет позиции после подтверждения получения. Касса формирует печатный документ о продаже для внутреннего учёта.

В отчёте за смену сначала вносится выработка, затем можно проверить расчёт норм и распределить комплекты между исполнителями. Проведение отражает выпуск, списание и сдельные начисления одной операцией. Привязка к версии спецификации сохраняется в документе.
